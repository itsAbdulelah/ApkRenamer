# استوديو تعديل وتكرار التطبيقات (ApkRenamer Studio)

أداة متطورة وعصرية لتعديل، تكرار (استنساخ)، وإعادة توقيع تطبيقات أندرويد (APK). تتيح لك تغيير اسم التطبيق، ومعرّف الحزمة (Package ID)، واستبدال أو الحفاظ على الأيقونة بسهولة تامة، مع ميزة الاستنساخ العميق (Deep Renaming) لتثبيت نسختين من نفس التطبيق جنباً إلى جنب دون تعارض.

تتضمن هذه النسخة كلاً من نواة الأوامر البرمجية (CLI) الأصلية مع **واجهة رسومية بلورية حديثة (Crystal Glass GUI)** تدعم اللغتين العربية والإنجليزية وخط **Tajawal**.

## 🌟 أبرز مميزات هذه النسخة (Fork Features)
- **تصميم زجاجي بلوري عصري (Crystal Glass):** مظهر جذاب وأنيق مع دعم كامل للنمطين الداكن والفاتح.
- **ثنائي اللغة مع دعم كامل للاتجاهين (RTL / LTR):** تبديل سلس وفوري بين العربية والإنجليزية مع تعديل تلقائي لتوزيع العناصر والمحاذاة.
- **خط تجوال (Tajawal):** مدمج بالكامل ومحمل تلقائياً لتقديم خط عربي أنيق ومتصل بأعلى وضوح.
- **مولّد معرّف الحزمة العشوائي (🎲):** إنشاء معرف حزمة فريد وصالح بضغطة زر لتسهيل استنساخ التطبيقات.
- **خيار الحفاظ على الأيقونة الأصلية:** إمكانية الاحتفاظ بشعار التطبيق الأصلي أو رفع صورة PNG جديدة مع معاينة فورية.
- **حل مشكلة المسارات العربية في ويندوز:** معالجة تلقائية للمسارات عبر نظام أسماء 8.3 القصيرة لمنع خطأ `aapt2` في مجلدات المستخدم التي تحتوي على أحرف خاصة أو يونيكود.
- **نسخة تنفيذية مستقلة (.exe):** ملف تنفيذي جاهز للتشغيل المباشر دون الحاجة لتثبيت بايثون أو ضبط أي إعدادات.

## 🚀 تشغيل الواجهة الرسومية

### الطريقة 1: التحميل الجاهز (الأسهل)
حمّل ملف التشغيل المباشر من [صفحة الإصدارات Releases](https://github.com/itsAbdulelah/ApkRenamer/releases/tag/v2.0.0-gui) وفك الضغط ثم شغّل `ApkRenamerGUI.exe`.

### الطريقة 2: التشغيل السريع من السورس كود (ويندوز)
اضغط مرتين على الملف:
```bat
run.bat
```

### الطريقة 3: بواسطة سطر أوامر بايثون
```bash
pip install -r requirements.txt
python main.py
```

### الطريقة 4: تصدير ملف تنفيذي (.EXE) خاص بك
```bash
python build_exe.py
```
سيكون الملف التنفيذي جاهزاً في: `dist/ApkRenamerGUI/ApkRenamerGUI.exe`.

## 💻 استخدام سطر الأوامر (CLI الأصلية)
```bash
java -jar core/renamer.jar [-a] <مسار_الملف.apk> [-o] <مسار_الحفظ.apk> [-n] <الاسم_الجديد> [-p] <معرف.الحزمة.الجديد> [-i] <مسار_الأيقونة.png>
```

- `[-d]`: استنساخ عميق (تغيير معرّف الحزمة داخل ملفات الـ Smali للتشغيل كنسخة ثانية مكررة).
- `[-t]`: استخراج الموارد إلى مجلد temp للتعديل اليدوي.
- `[-m]`: تخطي تعديل الموارد.
- `[-da]`: أوامر فك الحزم الإضافية لـ Apktool (مثل: `-da "--keep-broken-res"`).
- `[-ba]`: أوامر إعادة البناء لـ Apktool (مثل: `-ba "--use-aapt2"`).
- `[-r] <مسار_القاموس.txt>`: استبدال النصوص عبر ملف قاموس خارجي.
